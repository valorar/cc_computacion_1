Pregunta guía
¿Cómo sabemos que una función cumple lo prometido incluso con datos inesperados?
01 / FUNCIONES

Nombrar una tarea y reutilizarla

Una función recibe parámetros y comunica un resultado con return. Imprimir y devolver no son equivalentes.

def area_rectangulo(ancho, alto):
    if ancho < 0 or alto < 0:
        return None
    return ancho * alto

area = area_rectangulo(3.5, 2)
print(area)

El área cero es válida; None queda reservado para dimensiones inválidas.

02 / CONTRATOS

Entrada, salida y condiciones explícitas

Un contrato explica qué acepta la función, qué devuelve y qué ocurre fuera del dominio.

def inicial(texto):
    """Devuelve la primera letra no blanca o None si no existe."""
    limpio = texto.strip()
    if limpio == "":
        return None
    return limpio[0].upper()
Contrato comprobableUna promesa precisa se puede convertir en casos de prueba.
03 / DESCOMPOSICIÓN

Coordinar piezas pequeñas

Separar validación, cálculo y presentación reduce dependencias y repetición.

def es_temperatura_valida(valor):
    return -90 <= valor <= 60

def celsius_a_fahrenheit(celsius):
    if not es_temperatura_valida(celsius):
        return None
    return celsius * 9 / 5 + 32

Si cambia el dominio, hay un único lugar que modificar y probar.

04 / PRUEBAS

Casos elegidos para descubrir fallos

Una prueba compara obtenido y esperado. Incluye caso normal, fronteras, valores cercanos e inválidos. assert hace visible el incumplimiento.

assert area_rectangulo(3, 2) == 6
assert area_rectangulo(0, 8) == 0
assert area_rectangulo(-1, 8) is None
assert inicial("  ana") == "A"
assert inicial("   ") is None

Estas pruebas aportan evidencia repetible, aunque no demuestran corrección para toda entrada imaginable.

05 / DEPURACIÓN

Del síntoma a la causa

Depurar: reproducir, reducir, formular hipótesis, observar variables, corregir una causa y repetir pruebas.

def media(valores):
    if not valores:
        return None
    total = sum(valores)
    resultado = total / len(valores)
    return resultado

print("media([]) ->", media([]))

Tras corregir se conserva una prueba de regresión para impedir que el fallo reaparezca.

06 / SALIDA

Lo esencial

  1. Una función devuelve un resultado reutilizable.
  2. Un contrato vuelve comprobables las expectativas.
  3. Descomponer separa responsabilidades.
  4. Las pruebas cubren normales, fronteras e inválidos.
  5. Depurar reúne evidencia hasta localizar una causa.

Comprobación rápida: explica una idea con un ejemplo ejecutado y conserva la salida como evidencia.
