Pregunta guía
¿Cómo convierte un programa el texto de una persona en un resultado fiable?
01 / PROGRAMA

Instrucciones ejecutables desde el primer día

Un programa de Python es un archivo de texto que el intérprete ejecuta de arriba abajo. No necesitamos una unidad previa de pseudocódigo: escribimos, ejecutamos, observamos y corregimos código real.

nombre = "Lina"
print("Hola,", nombre)
print("Caracteres:", len(nombre))

La sangría, las comillas y los paréntesis tienen significado. Guardar antes de ejecutar evita comparar una salida nueva con código antiguo.

02 / DATOS

Variables, valores y tipos

Una variable asocia un nombre con un valor. int, float, str y bool representan clases de datos distintas. None expresa «sin dato» o «resultado inválido» sin confundirlo con cero o texto vacío.

ciudad = "Getafe"
temperatura = 18.5
hay_alerta = False
ultima_medicion = None
print(type(temperatura), ultima_medicion)
Idea claveEl nombre explica el papel del dato; el tipo determina qué operaciones tienen sentido.
03 / EXPRESIONES

Operadores, precedencia y resultados

Una expresión combina valores y produce otro. Python aplica precedencia; los paréntesis hacen explícita la intención. / divide, // obtiene cociente entero y % el resto.

minutos = 95
horas = minutos // 60
resto = minutos % 60
precio_final = round(12.50 * (1 - 0.20), 2)
print(horas, resto, precio_final)

Probar 0, 1, negativos pertinentes y decimales descubre supuestos ocultos.

04 / ENTRADA Y SALIDA

Conversar con quien usa el programa

input() siempre devuelve texto. Antes de calcular hay que convertirlo. Una salida útil incluye contexto y unidades.

texto = input("Edad en años: ")
if texto.strip().isdigit():
    edad = int(texto)
    print(f"El próximo año tendrás {edad + 1} años.")
else:
    edad = None
    print("No se ha introducido una edad válida.")

El control evita tratar una entrada vacía o alfabética como número; más adelante ampliaremos la validación.

05 / ERRORES

Leer el rastro antes de cambiar código

Un traceback indica tipo, archivo y línea. SyntaxError impide interpretar; NameError usa un nombre inexistente; ValueError puede señalar una conversión inadecuada.

dato = "doce"
try:
    cantidad = int(dato)
except ValueError:
    cantidad = None
print(cantidad)

Corregir empieza por reproducir y registrar entrada, mensaje y línea. Se captura solo el error previsto, no cualquier excepción.

06 / SALIDA

Lo esencial

  1. Python ejecuta instrucciones reales en orden.
  2. Cada valor tiene un tipo y cada variable un propósito.
  3. Las expresiones producen valores y las unidades aclaran su sentido.
  4. La entrada llega como texto y puede ser inválida.
  5. Un error reproducible aporta información.

Comprobación rápida: explica una idea con un ejemplo ejecutado y conserva la salida como evidencia.
