01 / MÉTODO

Una clase es un ciclo de trabajo

Las explicaciones son breves y tienen una misión: dar las herramientas necesarias para empezar a investigar, construir y corregir.

Orientarse

Leemos la pregunta guía y revisamos solo la teoría imprescindible para comprender el reto.

Probar

Manipulamos datos, sistemas, documentos o código. El error se trata como información, no como fracaso.

Construir

Cada práctica produce una evidencia real y conservable: archivo, programa, informe, publicación o registro de pruebas.

Comprobar

Una lista de control, pruebas automáticas o una rúbrica breve permite saber qué funciona y qué debe revisarse.

Explicar

El cuestionario autocorregible de Moodle comprueba si sabemos interpretar y aplicar, no solo recordar palabras.

El acuerdo de aula

No hay deberes para casa ni notas basadas en observaciones informales. El trabajo, la ayuda del profesor y la evaluación suceden en clase; cada calificación queda respaldada por una entrega o por Moodle.

Evaluación transparente

La nota refleja lo que produces y comprendes

  • Las prácticas obligatorias permiten alcanzar un 10.
  • Las voluntarias solo se abren al completar las obligatorias.
  • Una voluntaria incompleta o que no mejora la media se ignora.
  • No existen notas mínimas ni filtros entre apartados.
  • La calificación máxima siempre es 10.
