Pregunta guía
¿Cómo aseguramos que un programa elige la rama correcta y no repite para siempre?
01 / CONDICIONES

Comparar produce valores booleanos

Las comparaciones producen True o False. Una frontera pertenece a una rama: por eso 17, 18 y 19 son casos distintos.

edad = 18
tiene_autorizacion = True
puede_entrar = edad >= 18 and tiene_autorizacion
print(puede_entrar)

and exige ambas condiciones, or al menos una y not invierte.

02 / SELECCIÓN

Una decisión, caminos distintos

En if–elif–else se ejecuta la primera condición verdadera. El orden importa si hay intervalos solapados.

nota = 7.4
if not 0 <= nota <= 10:
    nivel = None
elif nota >= 9:
    nivel = "sobresaliente"
elif nota >= 5:
    nivel = "superado"
else:
    nivel = "en proceso"
print(nivel)
Casos límitePrueba justo por debajo, en y justo por encima de cada frontera, además de fuera del dominio.
03 / RECORRIDOS

for: recorrer una secuencia conocida

for conviene al recorrer elementos o un rango. range(inicio, fin) incluye el inicio y excluye el final.

total = 0
for numero in range(1, 6):
    total += numero
    print(numero, total)
print("Total:", total)

Tras cada vuelta, total contiene la suma ya procesada: un invariante sencillo.

04 / REPETICIÓN

while: repetir hasta que cambie la condición

while sirve cuando no sabemos cuántos intentos harán falta. Debe existir una acción que acerque la condición a False.

intentos = 3
while intentos > 0:
    print("Intentos:", intentos)
    intentos -= 1
print("Fin")

Una cota máxima es más segura que confiar en que una futura entrada será correcta.

05 / TRAZAS

Ver el estado para explicar el comportamiento

Una traza registra, vuelta a vuelta, variables relevantes y salida. Hace visible por qué aparece un resultado.

n = 13
pasos = 0
while n != 1 and pasos < 20:
    n = n // 2 if n % 2 == 0 else 3 * n + 1
    pasos += 1
    print(pasos, n)
resultado = pasos if n == 1 else None

La condición doble aporta una cota; None señala que no hubo resultado dentro de ella.

06 / SALIDA

Lo esencial

  1. Las fronteras deben probarse.
  2. El orden de las ramas cambia el camino.
  3. for recorre elementos conocidos.
  4. while necesita progreso y salida.
  5. Las trazas convierten el estado en evidencia.

Comprobación rápida: explica una idea con un ejemplo ejecutado y conserva la salida como evidencia.

07 / EVIDENCIAS

Prácticas del tema

Las tres prácticas son obligatorias, se realizan y entregan íntegramente en el aula y forman parte del 70% de prácticas. No hay deberes ni nota mínima por apartado.

Bonos del polideportivo

P01 · OBLIGATORIA

El polideportivo aplica precios por edad y número de accesos. Implementa las reglas entregadas y prepara casos justo antes, en y después de cada frontera; una edad inválida produce None.

Producto
apellido_nombre_t13_p01.zip con programa, tabla y ejecuciones.
Tiempo
Una sesión; individual.
Comprobación
Ramas no solapadas, límites correctos, None fuera de dominio y seis casos.

Cierre seguro del armario

P02 · OBLIGATORIA

El responsable del material dispone de tres intentos para confirmar un código de cierre simulado. El programa debe terminar por acierto, cancelación vacía o agotamiento e indicar cuál ocurrió.

Producto
apellido_nombre_t13_p02.py y tres recorridos completos.
Tiempo
Una sesión; prueba por parejas, entrega individual.
Comprobación
Estado inicial, actualización, cota y recorridos de éxito inmediato, tardío y agotamiento.

Marcador de la carrera solidaria

P03 · OBLIGATORIA

El marcador provisional contiene dos bucles: uno pierde la última vuelta y otro puede no terminar con una marca vacía. Traza ambos, corrige lo mínimo y reejecuta con 0, 1, el máximo y ausencia de marca.

Producto
apellido_nombre_t13_p03.pdf y archivos corregidos.
Tiempo
50 minutos; diagnóstico individual.
Comprobación
Traza, causa, corrección justificada, límites y salida antes/después.
Prácticas voluntarias: solo se desbloquean tras terminar todas las obligatorias de la evaluación. Solo cuentan si mejoran la media de prácticas; nunca la reducen ni sustituyen una obligatoria.
