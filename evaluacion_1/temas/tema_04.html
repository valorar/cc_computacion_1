El sistema operativo y los archivos

Entre una aplicación y el hardware hay un sistema que reparte recursos, protege usuarios y convierte bloques de almacenamiento en carpetas y archivos recuperables.

Pregunta guía
¿Qué tiene que ocurrir para que dos personas usen el mismo ordenador sin perder ni revelar sus archivos?
01 / ABSTRACCIÓN

El sistema operativo convierte hardware en servicios

El sistema operativo coordina procesador, memoria, almacenamiento, periféricos y red. Su núcleo trabaja con privilegios elevados; los controladores traducen operaciones generales a dispositivos concretos; los servicios atienden tareas en segundo plano; la interfaz permite al usuario pedir acciones.

Una aplicación no necesita conocer cada modelo de disco para guardar. Solicita al sistema crear, escribir o leer un archivo. Esta abstracción simplifica el desarrollo y permite controlar quién accede a cada recurso.

Núcleo

Planifica procesos, administra memoria, dispositivos y protección.

Interfaz

Expone operaciones mediante ventanas, menús, terminal o API.

02 / REPARTO

Un programa en ejecución es un proceso

El archivo de una aplicación contiene instrucciones; al ejecutarlo, el sistema crea un proceso con memoria, estado, recursos abiertos y permisos. Un mismo programa puede originar varios procesos. Los hilos permiten distintas secuencias de trabajo dentro de un proceso.

El planificador reparte tiempo de CPU y la memoria virtual ofrece a cada proceso un espacio de direcciones protegido. Si una aplicación deja de responder, puede estar esperando una entrada, bloqueada o consumiendo recursos: observar CPU, memoria y disco aporta más que cerrar todo.

Distinción observablePrograma es código almacenado; proceso es una ejecución concreta con estado y recursos.
03 / LOCALIZACIÓN

Una ruta describe dónde está un archivo

Los sistemas de archivos organizan información en jerarquías. Una ruta absoluta parte de la raíz del sistema o volumen; una ruta relativa parte de la carpeta de trabajo. ../ significa «carpeta superior» y ./, «carpeta actual».

RutaTipoInterpretación
/Usuarios/ana/proyecto/datos.csvAbsolutaUbicación completa desde la raíz
imagenes/logo.svgRelativaSubcarpeta desde la ubicación actual
../compartido/guia.pdfRelativaSube un nivel y entra en compartido

Los nombres deben ser previsibles: informe_final_v2.pdf informa mejor que nuevo definitivo bueno.pdf. Conviene evitar depender de mayúsculas, espacios o caracteres que otros sistemas tratan de manera distinta.

04 / INTERPRETACIÓN

Extensión, formato y aplicación no son lo mismo

El formato define cómo se organizan los bytes; la extensión es una pista en el nombre; la aplicación interpreta el formato. Cambiar .jpg por .pdf no convierte la imagen: solo cambia la etiqueta.

Los metadatos describen tamaño, fechas, autoría o dimensiones. Algunos viajan dentro del archivo y otros pertenecen al sistema de archivos. Pueden ayudar a encontrar y verificar documentos, pero también revelar ubicación o identidad al compartirlos.

FormatoUso adecuadoRiesgo frecuente
TXT/MarkdownTexto simple y portablePerder diseño complejo
PDFDistribución con aspecto estableDificultar edición o accesibilidad si se genera mal
CSVDatos tabulares intercambiablesSeparadores y codificación ambiguos
ZIPAgrupar y comprimirAceptar contenido desconocido sin revisar
05 / PROTECCIÓN

Disponibilidad, permisos y copias resuelven problemas distintos

Los permisos determinan quién puede leer, modificar o ejecutar. Se asignan a usuarios y grupos con el principio de mínimo privilegio: conceder solo lo necesario. Una carpeta compartida no debería dar edición a quien solo necesita consultar.

Sincronizar mantiene versiones entre ubicaciones, pero puede propagar un borrado. Una copia de seguridad conserva una copia recuperable; debe probarse la restauración. La regla 3-2-1 propone tres copias, en dos soportes, con una fuera del lugar principal.

Una copia existe cuando se puede restaurar

Ver un icono verde no demuestra recuperación. Hay que registrar qué se copia, cuándo, dónde, durante cuánto tiempo y realizar una restauración de prueba.

06 / SALIDA

Lo esencial

  1. El sistema operativo ofrece servicios y controla recursos compartidos.
  2. Un proceso es una ejecución concreta de un programa.
  3. Las rutas relativas dependen del punto de partida; las absolutas, de una raíz.
  4. La extensión no transforma el formato real de un archivo.
  5. Los permisos limitan acceso; la copia permite recuperar.
  6. Organizar bien implica poder encontrar, compartir y restaurar con criterios repetibles.
