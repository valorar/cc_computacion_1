Pregunta guía
¿Qué estructura responde preguntas sobre muchos datos con menos errores y una intención más clara?
01 / COLECCIONES

Elegir por las operaciones necesarias

Una cadena es texto ordenado e inmutable; una lista mantiene orden y cambia; una tupla agrupa valores fijos; un conjunto elimina duplicados; un diccionario asocia claves y valores.

etiquetas = ["sol", "viento", "sol"]
unicas = set(etiquetas)
mediciones = {"aula": 21.5, "patio": 18.0}
posicion = (40.4, -3.7)
print(len(etiquetas), len(unicas), mediciones["aula"])

La elección depende de si necesitamos orden, repetidos, búsqueda por clave o modificación.

02 / SECUENCIAS

Índices, cortes y copias

Las secuencias empiezan en 0 y los cortes excluyen el límite final. Una posición inexistente provoca IndexError.

palabra = "algoritmo"
primeras = palabra[:4]
valores = [8, 3, 5]
copia = valores.copy()
copia.append(13)
print(primeras, valores, copia)

copia = valores no crea otra lista: ambos nombres señalarían el mismo objeto.

03 / RECORRIDOS

Procesar elementos sin administrar índices

Si necesitamos valores, recorremos directamente. enumerate añade posiciones cuando son parte real del problema.

temperaturas = [18.5, 21.0, 19.5]
total = 0.0
for posicion, temperatura in enumerate(temperaturas, start=1):
    total += temperatura
    print(posicion, temperatura)
media = total / len(temperaturas) if temperaturas else None
print(media)

«Sin datos» no significa «medición cero»; por eso la media vacía es None.

04 / BÚSQUEDA

Encontrar sin confundir ausencia e índice cero

in comprueba pertenencia. None evita confundir «no encontrado» con el índice 0.

nombres = ["Ana", "Luis", "Marta"]
buscado = "Luis"
posicion = None
for indice, nombre in enumerate(nombres):
    if nombre == buscado:
        posicion = indice
        break
print(posicion)

break basta para la primera coincidencia; para todas acumulamos posiciones.

05 / TRANSFORMACIÓN

Crear resultados sin destruir el origen

Transformar construye una colección derivada. Mantener el original permite auditar y repetir.

lecturas = [12, -1, 18, 999, 20]
validas = []
for lectura in lecturas:
    if 0 <= lectura <= 50:
        validas.append(lectura)
print("Original:", lecturas)
print("Válidas:", validas)
Evidencia materialConserva entrada, regla de filtrado y salida.
06 / SALIDA

Lo esencial

  1. Cada colección favorece operaciones distintas.
  2. Los índices empiezan en cero.
  3. Recorrer valores reduce errores.
  4. None distingue ausencia de posición válida.
  5. Una transformación auditable conserva entrada, regla y salida.

Comprobación rápida: explica una idea con un ejemplo ejecutado y conserva la salida como evidencia.
